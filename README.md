# Mini Soundboard — version glisser-déposer

Cette version accepte le glisser-déposer d'un ou plusieurs fichiers audio directement dans la zone prévue.

Mise en ligne : héberge les fichiers sur un site HTTPS (GitHub Pages convient), puis ouvre l'adresse dans Chrome et installe la PWA.

Les sons sont conservés localement sur l'appareil via IndexedDB.
